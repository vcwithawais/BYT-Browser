## About me

- 🔭 Currently building **[BYT Browser](https://github.com/vcwithawais/BYT-Browser)** — a stateless Electron browser with a real Tor mode.
- 🧠 Deep in **Chromium session isolation**, **Tor/SOCKS5 proxying** and **DNS-leak prevention**.
- 🧩 I like the boring parts done right: clean architecture, small modules, no hidden data collection.
- 💬 Ask me about **Electron**, **Node.js**, browser internals or building a UI that feels native.
- ⚡ Principle I build by: if it doesn't need to be stored, it doesn't get stored.
